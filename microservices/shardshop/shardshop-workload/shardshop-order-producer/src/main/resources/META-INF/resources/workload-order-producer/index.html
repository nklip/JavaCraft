About this control

  • Rate counts new orders. Allocation, submission, status polling, retries and startup traffic are separate rows below.
  • One order is in flight at a time: when orders take longer than the target interval, a notice shows the reachable rate.
  • Setting lives in the workload process. Refreshing or closing this page keeps it; a process restart restores the default rate, unpaused.
  • Pause lets the operations in flight finish within their deadlines; zero also stops new work. A change never sends missed work later.
  • Pause finishes observing the current order before it stops new allocations. Run name, ordinals, IDs, retry keys and currencies do not change.
