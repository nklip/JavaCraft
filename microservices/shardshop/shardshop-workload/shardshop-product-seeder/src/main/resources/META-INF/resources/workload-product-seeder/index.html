About this control

  • Rate counts every outgoing HTTP request, including repeated attempts, creation and verification.
  • Runs reuse the dataset keys and payloads: a rerun creates no duplicates and changes no stock or earnings. The bootstrap Job of each deployment is separate.
  • Setting lives in the workload process. Refreshing or closing this page keeps it; a process restart restores the default rate, unpaused.
  • Pause lets the operations in flight finish within their deadlines; zero also stops new work. A change never sends missed work later.
  • Timeouts apply to each HTTP attempt; a paused run has no deadline and waits for Resume.
